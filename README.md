# RoadGuard AI

## AI-Based Road Damage Detection and Reporting System

RoadGuard AI is a full-stack application that uses artificial intelligence to detect road damage from images and allows users to submit and track road damage reports.

## Features

- User registration and login
- JWT-based authentication
- AI-based road damage detection
- Road damage report submission
- Damage confidence and severity information
- Location-based reporting
- User report tracking
- Admin dashboard
- Admin report filtering
- Admin status management
- MySQL database integration

## Technology Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MySQL
- JWT Authentication

### AI Service
- Python
- FastAPI
- Ultralytics YOLO
